# 가족 의견 창구 연결하기 (5분)

사이트의 **의견 남기기**는 민석 구글 계정의 구글 시트에 저장돼요. 가족들은 로그인 없이 쓸 수 있어요.
한 번만 아래대로 설정하면 돼요.

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 에서 새 스프레드시트를 만들고 이름을 `제주여행 의견` 으로 바꿔요.

## 2. 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script**
2. 원래 있던 코드를 지우고, 이 폴더의 `apps-script.gs` 내용을 통째로 붙여넣은 뒤 **저장**(디스크 아이콘)

## 3. AI 비밀번호 넣기 (AI 자동 조사용)
1. 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **스크립트 속성 추가**
2. 속성 `AI_TOKEN`, 값은 Claude가 채팅으로 알려준 문자열 → **저장**

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니 → 유형 **웹 앱**
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자** → **배포**
4. 권한 허용 창이 뜨면 계정 선택 → (경고가 나오면) 고급 → 이동 → 허용
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사해서 Claude에게 보내주세요

그러면 사이트의 `data/trip.js` 에 주소를 넣어 연결해요.

## 관리
- 시트의 `의견` 탭에 모든 의견이 쌓여요.
- 지우고 싶은 의견은 그 줄의 `hidden` 칸에 아무 글자나 적으면 사이트에서 사라져요.
- 코드를 고친 뒤엔 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영돼요.

## 저녁 투표 · 가족 사진첩 켜기 (코드 업데이트, 3분)
사이트의 **저녁 투표**와 **가족 사진첩**은 새 코드가 있어야 동작해요. 한 번만 하면 돼요.

1. 시트 → **확장 프로그램 → Apps Script** → 원래 코드를 지우고 이 폴더의 `apps-script.gs` 를 통째로 붙여넣기 → **저장**
2. **톱니바퀴(프로젝트 설정) → 스크립트 속성 추가**: 속성 `PHOTO_KEY`, 값은 가족끼리 쓸 비밀번호 (예: 태오생일 숫자 4자리) → 저장
   - 사진은 이 비밀번호를 넣은 사람만 보고 올릴 수 있어요. 단톡방에 비밀번호를 알려주세요.
3. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
   - 주소(URL)는 그대로라 사이트는 안 고쳐도 돼요.
   - 구글 드라이브 권한을 새로 묻는 창이 뜨면 계정 선택 → 고급 → 이동 → **허용**
4. 사진은 내 구글 드라이브의 `제주여행 사진첩` 폴더에 저장돼요. 지우고 싶은 사진은 시트 `사진` 탭에서 그 줄의 `hidden` 칸에 아무 글자나 적으면 돼요.
